===============================================================================
Simple Syntax..........

Use the event name in methods like addEventListener(), or set an event handler property.
=> addEventListener("mouseover", (event) => { })
onmouseover = (event) => { }


Event type..............
A MouseEvent. Inherits from UIEvent and Event.

Event <-- UIEvent <-- MouseEvent.....
===========================================================
Element: mouseover event
===========================================================

Event properties
_______________________________________________________________
This interface also inherits properties of its parents, UIEvent and Event.

1. MouseEvent.altKey ..............
Returns true if the alt key was down when the mouse event was fired.

2. MouseEvent.button ..............
The button number that was pressed (if applicable) when the mouse event was fired.

3. MouseEvent.buttons ..............
The buttons being pressed (if any) when the mouse event was fired.

4. MouseEvent.clientX ..............
The X coordinate of the mouse pointer in viewport coordinates.

5. MouseEvent.clientY ..............
The Y coordinate of the mouse pointer in viewport coordinates.

6. MouseEvent.ctrlKey ..............
Returns true if the control key was down when the mouse event was fired.

7. MouseEvent.layerX Non-standard ..............
Returns the horizontal coordinate of the event relative to the current layer.

8. MouseEvent.layerY Non-standard ..............
Returns the vertical coordinate of the event relative to the current layer.

9. MouseEvent.metaKey ..............
Returns true if the meta key was down when the mouse event was fired.

10. MouseEvent.movementX ..............
The X coordinate of the mouse pointer relative to the position of the last mousemove event.

11. MouseEvent.movementY ..............
The Y coordinate of the mouse pointer relative to the position of the last mousemove event.

12. MouseEvent.offsetX ..............
The X coordinate of the mouse pointer relative to the position of the padding edge of the target node.

13. MouseEvent.offsetY ..............
The Y coordinate of the mouse pointer relative to the position of the padding edge of the target node.

14. MouseEvent.pageX ..............
The X coordinate of the mouse pointer relative to the whole document.

15. MouseEvent.pageY ..............
The Y coordinate of the mouse pointer relative to the whole document.

16. MouseEvent.relatedTarget ..............
The secondary target for the event, if there is one.

17. MouseEvent.screenX ..............
The X coordinate of the mouse pointer in screen coordinates.

18. MouseEvent.screenY ..............
The Y coordinate of the mouse pointer in screen coordinates.

19. MouseEvent.shiftKey ..............
Returns true if the shift key was down when the mouse event was fired.

20. MouseEvent.mozInputSource Non-standard ..............
The type of device that generated the event (one of the MOZ_SOURCE_* constants). This lets you, for example, determine whether a mouse event was generated by an actual mouse or by a touch event (which might affect the degree of accuracy with which you interpret the coordinates associated with the event).

21. MouseEvent.webkitForce Non-standard ..............
The amount of pressure applied when clicking.

22. MouseEvent.x ..............
Alias for MouseEvent.clientX.

23. MouseEvent.y ..............
Alias for MouseEvent.clientY.
